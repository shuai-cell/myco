# DeepSeek Harness desktop support

On Windows, myco can run DeepSeek Harness (DSH) through its ACP profile. If `dsh.exe` is on `PATH`, myco runs it directly. Otherwise, myco looks for the unpacked DSH CLI under the desktop installation recorded in the Windows uninstall registry and invokes it with `node.exe` from `PATH`.

Settings > Agents reports DSH as installed when the CLI is found. Configure a model in DeepSeek Harness before starting a DSH agent. Detection does not test credentials or make a model request.

Add agent > This computer > New session > DeepSeek Harness (DSH) starts `dsh --profile acp`. Its ACP profile must support `session/new`, `session/prompt`, and session resume. The default and read-only access settings request DSH's `read-only` permission mode; Workspace requests `workspace-write`; Full requests `danger-full-access`. These mappings depend on DSH honoring `DSH_PERMISSION_MODE`.

After a DSH session reports its model choices, the App can select one for the agent's next run. The selection is applied when the runner resumes the same DSH session. Clearing the selection leaves the model chosen by the DSH session unchanged.
